# 教学工具箱（Pedagogy Playbook）

本文件为 `interactive-doc-tutor` 提供可按需调用的教学方法与动画触发准则。

## 1. 知识锚点类比（Anchor Mapping）

永远优先用学习者在阶段 0 确认过的熟悉领域建立桥梁，而不是用生造的抽象定义开场：

- **有 LLM 推理工程背景** → 优先用张量形状 `[seq_len, d_model]`、`Prefill / Decode`、`KV Cache`、`Attention Mask`、`BPE Tokenizer` 解释视觉 Patch、动作分词、多步去噪复用等概念。
- **有 RL（MDP / PPO / GRPO / DPO）背景** → 跳过入门 RL 科普，直接从“在线采样的真机代价 vs 离线条件化（Advantage Tagging / AWR / DPO）”的工程权衡切入。
- **零基础领域** → 先用身体直觉或日常系统（如视频播放器缓冲队列、手指按桌面摆动手肘）建立物理画面，再引出准确数学定义。

## 2. 公式推导规范（当学习者偏好推导时）

- **问题引出**：先给一句物理/直觉问题（为什么朴素做法会失败？例如 L2 回归在多峰分布下求平均导致撞墙）。
- **逐零件拆解**：遇到包含期望、采样、范数或复杂下标的核心公式（如训练 Loss），**不要抛完公式直接跳过**——必须用 `\underbrace` 或分点逐一拆解每个符号的来源、输入输出与几何含义；若有配图，显式建立**“符号 ↔ 画布颜色/元素”的映射**（如“绿色箭头 = 真实速度，红色虚线长度平方 = Loss”）。
- **最小代码落地**：面对有工程/代码背景的学习者，推导完核心 Loss 或推理循环后，顺手附 **5–8 行最简 PyTorch/NumPy 伪代码**（标明核心张量形状），把数学期望瞬间翻译成 Batch 训练代码。
- **关键机制给严格代数证明**：涉及“某性质必然成立”的架构论断（如单向分块 Mask 锁死多层 KV Cache），除了直观图解，尽量补上 **3–5 行分块矩阵/归纳推导** 封口。

## 3. 何时触发 HTML 交互动画（`generative_ui`）

**首轮讲解就应主动配交互动画的场景（不要等卡住再补）：**
- 多维空间运动与几何映射（如机械臂关节角 vs 末端位姿 + IK）；
- 分布与轨迹演变（如 Flow Matching 直线插值、速度场与 10 步欧拉积分）；
- 非标准神经网络形态与多层状态传播（如双塔维度对齐、Blockwise Causal Mask 与多层 KV Cache 污染对比）；
- 时域/频域变换（如连续动作波形经 DCT 压缩与重构）；
- 多代系统横向对比（如可点击切换的版本演进总控台）。

**不需要做动画的场景：**
- 简单定义、纯文字对比或一步算术推导（用清晰文本/ASCII 链路图更快更准）。

**动画设计约束：**
- 保持聚焦，只服务**当前正在讲的微模块**，复杂模块可拆成 2 个 Tab（如“训练视角 vs 推理视角”、“静态结构 vs 动态传播”）；
- 涉及高维投影（如 900 维 → 2D）时，在界面顶部显式注明降维前提；
- 在未加载 KaTeX 的独立 HTML 中，统一使用清晰的 Unicode 数学符号（如 `τ, θ, Σ, α, ‖·‖², A₀, A₁`），**避免出现未渲染的原始 `$...$`**；
- 遵循 `generative_ui` 主题规范，确保文字与画布对比度清晰。

## 4. 苏格拉底检验与费曼复述

- 每关最多抛 **1 个** 高杠杆问题，问题必须紧扣学习者的已有背景（例如让懂 KV Cache 的人自己推断 Attention Mask 应该怎么遮挡）。
- 学习者答偏时，不直接否定，先肯定合理部分，再给一个反例引导其自己发现漏洞。
