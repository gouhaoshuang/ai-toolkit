# 学习者私有画像规范（Learner Profile Guide）

为了避免每次学习新文档都重复介绍自己的技术栈与节奏偏好，本 skill 支持在**本机私有配置目录**维护一份轻量级学习者画像：

- 默认路径：`~/.config/interactive-doc-tutor/profile.md`
- 权限建议：目录 `0700`、文件 `0600`
- **红线**：画像属于用户个人数据，**绝不写入本 skill 仓库或任何项目 Git 目录**。

## 推荐格式

```markdown
# 学习者画像

## 熟悉领域（可跳过基础科普、用作类比锚点）
- 文本 LLM 推理架构（写过 Qwen2.5 0.5B GPU+CPU 推理，熟悉 Transformer、Attention Mask、KV Cache、BPE、Prefill/Decode）
- 强化学习基础与 Agent RL（熟悉 MDP、Bellman 方程、PPO、GRPO、DPO）

## 仅了解概念 / 需补齐领域
- 扩散模型 / Flow Matching（了解从噪声逐步去噪的基本直觉，希望看公式推导）
- ViT / 多模态（已理解 1 Patch = 1 Token 的基本张量映射）

## 零基础领域（需从直觉与完整链路慢讲）
- 机器人控制（已掌握 6/7 自由度、关节控制 vs 末端控制 + IK、50Hz 与 Action Chunking）
- 信号处理（DCT 等）

## 教学偏好与交互约定
- 节奏：每轮只讲 1 个微模块，严禁跳步和隐性前提。
- 形式：混合式（类比 + 完整公式推导 + 抽象处配 HTML 交互动画 + 苏格拉底小问）。
- 追问响应：局部细节追问只精答该点；主线卡点追问（尤其标注“后面没看”时）需解开卡点并重接后续逻辑。
```

## 更新时机

- 仅在用户明确要求更新，或完成一门完整文档学习后征得用户同意时，将新掌握的知识点同步更新到 `profile.md`。
