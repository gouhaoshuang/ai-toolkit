# 图片转可编辑 PPT

交付与参考图内容一致、布局接近且能够继续编辑的 `.pptx`。这不是把整张图贴进幻灯片，也不是重新设计一份摘要；不要用“100% 还原”的承诺替代实际的内容核对和视觉检查。

## 理解当前要求

- 先列出输入图片，查看每张原图。多图默认按文件名自然排序、一图一页，生成一个合集；只在用户需要时拆分单页。存在两种合理排序且影响内容顺序时再询问。
- 明确用户要完整还原、局部修改，还是仅生成效果图。只请求效果图时不要提前修改 PPT；明确要求图片生成模型时再使用对应能力，普通还原无需生成式图像服务。
- 从图片尺寸建立画布，保留原比例，包括 4:3。混合比例时一个 PPT 只能有一种页面尺寸：选择合理统一画布、等比放置并留白，说明处理方式，不能拉伸图片或擅自裁内容。
- 保留当前任务和前文已确认的字体、缩放、截图处理及文件替换范围。微软雅黑、90% 居中缩放都不是本技能的通用默认。用户未指定时以原图为准。
- 修改既有 PPT 时先检查实际文字、图表数据和用户现有编辑。只改指定文件及页面；覆盖前保存同目录的版本化备份。不要因存在旧生成脚本就整份重跑覆盖用户修改，也不要自动改合集、压缩包或其他单页文件。

## 拆解与转录

1. 建立简短内容清单：区域边界、标题、逐行正文、公式、图表原始数值、图例分类、箭头起终点及需要保留的图像区域。放大局部检查密集内容；OCR 仅作辅助，以原图和原生源文件为准。
2. 按图层从底到顶重建：背景/面板 → 路径 → 节点 → 文字/公式 → 强调标记；必要时调整顺序，让路径连到框边且不穿过文字。优先还原内容及关系，再处理线宽、圆角、渐变与阴影。
3. 文字使用独立文本框或可编辑富文本。保留数值的小数位、正负号、大小写、英文框架名、下标、换行和强调色。字体装在本机与 PPT 声明了字体是两回事，不把替代字体的预览称为目标字体实测。
4. 方框、色块、坐标轴、简单图标、折线/曲线箭头和虚线用原生形状与连接线。按语义模块分组，避免整页变成不可拆的图片。不会自动识别原图的脚本不能宣称“一键精确转换”。
5. 表格使用原生表格。数据型图表优先用原生图表并保留数据工作簿；核对条目数量、分类颜色、轴范围、方向及数值。没有可靠精确数值的示意直方图可用逐柱形状重建，不编造数据。不要为了好看删基线、加框架、重排或重分类。
6. 公式优先保留可编辑的数学结构；简单公式可以用数学字体与真实上下标。文本公式只是可编辑文字，不等同 Office 公式对象。复杂分式、求和或矩阵的处理见 [references/reconstruction.md](references/reconstruction.md)。
7. 机器人、照片、复杂插画、校徽或明确允许保留的手机界面可以复制局部图像。裁切不要带入本应重建的标题、标签和其他图形；应使用实际局部文件，避免把整张原图藏在 PPT 裁剪区里。

## 实施工具

优先使用环境已有的演示文稿工具；本技能提供可移植的 `python-pptx` 辅助库和检查工具，不依赖特定连接器。发现本机工具与字体情况：

```bash
python /path/to/image-to-editable-ppt/scripts/pptx_tool.py doctor
python /path/to/image-to-editable-ppt/scripts/pptx_tool.py inventory /path/to/images
```

依赖为 Python 3.10+、`python-pptx`、Pillow、lxml。缺失时使用任务专用环境和 `scripts/requirements.txt`，不要升级污染共享环境。预览另需 LibreOffice 和 Poppler 的 `pdftoppm`。

为当前任务编写生成/修改脚本，保留在交付文件旁的工作目录，使用 [scripts/editable_ppt.py](scripts/editable_ppt.py) 减少重复的图形和 OOXML 操作。调用方法、字体与公式技巧、裁切、原生图表、缩放和常见兼容性问题见 [references/reconstruction.md](references/reconstruction.md)，实现时按需读取。辅助库使用**像素坐标与像素字号**，统一映射到物理幻灯片；不要混用源图像素与幻灯片点数。

## 核验与迭代

```bash
# 结构审计不能代替下面的视觉检查。
python /path/to/image-to-editable-ppt/scripts/pptx_tool.py audit /path/to/result.pptx --out /path/to/audit.json
python /path/to/image-to-editable-ppt/scripts/pptx_tool.py render /path/to/result.pptx --out-dir /path/to/preview
```

- 导出并查看**每一页**，与原图逐项对照：文字遗漏/误字、公式、标签截断、自动换行、编号居中、框大小、渐变、箭头方向、虚线路径、遮挡和页边距。定位问题后修正并重渲染受影响页面，不凭脚本运行成功就交付。
- 核对内容清单与图表的完整标签和原始数值，包括 `7.0`、`26.150` 等显示精度；读取保存后的 PPT 确认它们实际存在，而非只在生成脚本里正确。
- 检查原生元素、图片数量/范围、越界、OOXML 顺序和 ZIP 完整性。全页背景照片可以合理存在，但不能把整页截图当成已经完成可编辑还原。审计中的图片占比和越界只是线索，不能机械拒绝复杂插画或特效。
- 缩放前后核对组内形状、原生表格、文字和图表尺寸；不能只移动框而没有缩字体，或漏掉 `p:xfrm` 的表格框。辅助函数处理这些差异，但不负责自动解决溢出的长文本。
- 如果没有预览渲染器，交付结构检查结果并明确未进行视觉验证；不要用整页截图替代请求的可编辑成品。目标字体缺失时如实说明替代预览，不能擅自下载不明来源的商业字体。

## 交付

给出最终 `.pptx` 的可点击绝对路径，简述哪些内容可编辑、哪些复杂图像保留为图片。可附最终预览；说明影响使用的字体或还原限制，不重复所有内部步骤。不要把生成脚本、内容清单或 PDF 当成用户要求的最终 PPT。除非用户明确要求，不安装技能、不修改客户端配置、不提交或推送用户材料。
