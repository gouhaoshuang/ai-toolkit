# 可复用 SVG 视觉原语库（Visual Primitives）

画图的核心不是摆矩形填文字，而是为每一类逻辑挑选**“不用解释也能一眼看懂”的具象微图形**。以下 6 类原语均采用白底学术风，可直接组合进 `viewBox="0 0 W H"` 的单文件 SVG 中。

---

|---|---|---|---|---|
| 中性骨架 | `#CBD5E1` | `#F8FAFC` / `#FFFFFF` | `#0F172A` / `#475569` | 普通容器、流程箭头、辅助说明 |
| 主焦点（深红） | `#BE123C` | `#FFF1F2` | `#9F1239` | 核心模型调用、核心损失/更新、主痛点 |

## 原语 1：共享顶部锚点条（Shared Concrete Anchor）
**适用场景**：多方案对比、多阶段管线。
**为什么有效**：让所有泳道/阶段处理同一个具体例子，读者不用在脑中反复切换假设场景。
- 位置：画布最顶部标题下方，细圆角灰条（`height="34"`，`fill="#F8FAFC"`，`stroke="#E2E8F0"`）。
- 内容只放 3–4 个硬数据胶囊：`任务` + `原始尺寸/输入` + `目标真值`（例如 `在录音机中点击 Save 按钮` · `1080×2400` · `归一化(500,820)` / `像素(540,1968)` / `元素 #12`）。

---

## 原语 2：双轨时间轴 / 滑窗微图（Timeline & Sliding Window）
**适用场景**：展示历史记忆、上下文窗口、缓存淘汰、多轮对话差异。
**画法要点**：
- 明确标出当前步数（如 `第 7 步上下文`），不要只写抽象的 `t-4..t`。
- **丢弃帧**：小虚线灰方框 `[×]`（`stroke-dasharray="3,2"`）。
- **保留图帧**：圆角小卡片 `[图3][图4][图5][图6]` + 实心蓝 `[图7]` 表示当前帧；若做了缩放，用**肉眼可见更小的矩形**并标倍率（如 `0.62×`）。
- **溢出折叠为文本**：画一个虚线灰文本卡片，里面写**真实两行短例**（如 `Step 1: 打开录音机` / `Step 2: 点击开始录制`），旁边连箭头进滑窗，读者秒懂“旧图被剥离，只剩动作摘要”。
- **不对称保留**：拆成上下两条平行轨（上轨 `缩图轨` 只留后段，下轨 `助手轨` 从头到尾实心满格），不对称性瞬间可见。

---

## 原语 3：结构化输出形态块（Structured Output Block）
**适用场景**：对比不同 Agent / 模型 / API 的输出协议差异。
**画法要点**：
- 绝不用一根普通红箭头写“输出动作”敷衍。
- 在模型调用右侧单开一列，画圆角微卡片，按真实格式画出**带色条的分段微块**：
  - 多段 XML：画 3 条竖向小胶囊（`① 思考` / `② 动作` / `③ 结论`），若某一段被回传到记忆，**直接从该小胶囊引出虚线回流箭头**。
  - 坐标 vs 索引：用红/蓝高亮最关键的 1 个字段（如 `start_box='(500,820)'` vs `"index": 12` 旁加小标签 `无像素坐标`）。

---

## 原语 4：微型屏幕 / 空间示意图（Mini-Screen & Grounding）
**适用场景**：GUI Agent 截图、视觉定位、SoM 标注、点击距离衰减、操作前后对比。
**画法要点**：
- 画一个极简竖屏圆角手机框（约 `42×66px`），内部只放 2–3 个极简浅灰 UI 块 + 1 个高亮目标按钮（如 `Save`）。
- **像素点击 / 距离衰减**：在目标按钮中心画实心靶心 + 虚线圆圈（如 `r=50` 衰减边界），不同候选点 `o1, o2, o3` 直接点在对应位置上，远近一目了然。
- **SoM 标号**：在按钮外画绿色虚线框 + 左上角小绿标 `[12]`。
- **操作前后对比（如反思/验证）**：并排画两个微型手机框 `[前]` `vs` `[后]`，第二个框里按钮状态变化（如弹出已保存提示条），直观表达“双图对比”。

---

## 原语 5：数值翻转 / 阈值映射图（Number Line & Flip Visual）
**适用场景**：GRPO 组内归一化、奖励→优势翻转、评分门控、过滤阈值。
**画法要点**：
- **不要只写公式**！把具体样例（如 `o1..o4`）画成水平柱状条，在所有柱子上**贯穿一条垂直虚线代表均值 $\mu$**。
- 凡是低于均值线但本身为正数的柱子（例如 `r3 = +0.50 < μ = 0.5625`），在右侧直接画出**跨过 0 轴向左反转的红柱**（`Â3 = -0.146`），并用深红短标注点出“正分变负优势”的直觉痛点。

---

## 原语 6：分段裁剪 / 锚定曲线微图（Clip & Penalty Curve）
**适用场景**：PPO/GRPO/DAPO 非对称裁剪、Dual-Clip、KL 散度惩罚、学习率调度。
**画法要点**：
- 在极小坐标系（约 `220×130px`）中直接画出折线/曲线，用浅灰阴影标出安全区间（如 `[0.8, 1.3]`），把被截断的平顶段涂成深红/橙色，并把具体样例点（如 `o1: ρ=1.45→1.30`, `o4: ρ=0.65→0.80`）直接标在曲线拐点上。
- 让读者通过**折线变平的几何形状**秒懂“梯度停止放大”，而不是去背 `torch.max / torch.min` 嵌套公式。
